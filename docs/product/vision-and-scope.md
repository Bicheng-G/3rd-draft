# 产品定义与边界

状态：V1 产品方向与阶段边界 · 2026-10-02。依据：[用户需求](../research/founder-context.md)、已完成的 Walking Skeleton 与随后用户明确的完整 V1 / 英文界面要求。

## 当前执行边界（2026-10-05）

后继批准 ADR-017：个人/native Skill 发现或加载为 best effort，不再单独阻断执行。优先约束正常宿主文件、其他项目、provider/计费、外部操作与应用授权；不为指令纯度建立额外基础设施。已验证且前提未变的两次操作预算证据复用。

用户将下一里程碑收敛为领域/运行时隔离修正与原生图片制作的有界可行性判断；暂停外围 V1 扩展。已完成修正保留。后继批准允许每个显式 Production Action 最多 2 次图片操作，由 harness/runtime 强制限制；允许读取当前项目隔离/staged 文件区，禁止正常宿主和其他项目。显式参考选择仍入快照，但不再要求它们是区内唯一可读文件。独立 ChatGPT 登录及真实订阅路线须另证。FEASIBLE 时只做一条受控生成和一次显式编辑闭环；新边界仍不能证明则记录具体 BLOCKED。完整 V1 定义保留，不能用此里程碑替代全部发布门槛。见 [PRD 当前里程碑](prd-v0.1.md) 与 [验证记录](validation-v1.md)。

## 完整 V1 产品范围（保留）

用户在 v0.1 通过后明确要求继续实施完整 V1；此前“不继续 V1”的指令仅描述上一轮已结束范围，现由新请求接续。V1 采用下文完整图文工作台边界、[PRD 的 P0/NFR 与发布条件](prd-v0.1.md)及[完整评测协议](evaluation.md)。进度和不足见 [V1 验证记录](validation-v1.md)，不以范围已获授权推断功能已实现或质量已通过。

产品界面使用英文，生成内容语言由当前 brief 决定，英文界面与中英文内容支持相互独立。Windows 本地、单人多项目、项目拥有知识和资产、原生订阅优先、事实确认、可恢复执行等边界继续有效。FR-17 网站/PDF 扩展及 FR-18 第二图片 provider 仍留在 P1；团队、云端、多租户、自动发布、营销效果学习不在 V1 范围。

v0.1 的文字记忆闭环及其 20 项测试、两次真实生成是历史起点，原证据见[记录](validation-v0.1.md)。V1 须另证研究/洞察、完整创意与收藏复用、参考图制作与编辑、两种制作模式、Review、交付与备份，以及不低于手工流程的质量和操作时间；缺少真实基线时不得声称这些结论。

## 历史范围：v0.1 Walking Skeleton

v0.1 只验证一个可实际使用、跨两次创作的项目记忆闭环：保存知识或创作判断，经过相关上下文与版本化能力交给真实 runtime，归档文字作品，再将前次作品和有范围的反馈用于下一次创作。第二次创作在服务重启后进行，用户无需重述前次反馈，结果必须展示具体的上下文复用影响。

文本 caption 或创意文案是本次足够的作品形态。浏览器工作台、Windows 本地单人多项目、服务端项目隔离、用户确认品牌事实、BYOA 不静默转 BYOK、不可变历史和可追溯归档继续适用。详细关闭标准与运行证据见[验证记录](validation-v0.1.md)。

上一轮将原“v0.1”图文生产、全部工作流和对照质量发布门槛归入 **V1 完整产品基线**，只验证文字 Walking Skeleton 并停止。该停止条件已经履行；当前 V1 工作来自后续明确授权，不是由文字闭环自动扩张。

## 产品定义

面向独立创作者和多项目经营者的开源长期创意工作空间（Living Creative Workspace）。每个项目持续积累品牌知识、研究证据、客户洞察、创意和选择记录；用户按需研究、构思、收藏、发展或制作，逐次复用已有成果。

产品中心是 **Project 及其长期 Project Memory**：Brand Context、Research Library、Insight Bank、Creative Bank、作品与反馈。Creative Set 是一次有 brief 的创意发展/制作单元；创意可以先独立存在、收藏，之后被多个 set 引用。Agent 是完成工作的角色；聊天是修改与沟通手段；图片是有上下文和版本的交付物。

## 为谁解决什么问题

首个用户是已经用 ChatGPT Project 与 Nano Banana 完成创作的人。他能判断作品是否可用，也愿意选择创意方向，但不希望每次重新描述品牌、搬运整套上下文、整理文件和协调返工。

核心工作任务：

> 当我为某个品牌制作一组社交内容或广告时，我希望工作台调用正确的资料和风格，提出可选择的创意并完成图文制作，让我把精力放在方向和作品质量上，同时保留下一次可以继续使用的知识。

第二类场景是资料不完整的 hobby 项目：允许从少量描述开始，显式保留未知信息，不强迫先创建完整品牌手册。

## 用户应感受到的价值

| 当前负担 | 工作台承担的责任 | 可观察结果 |
|---|---|---|
| 重复输入项目背景 | 取用已确认的品牌和产品版本 | 切换项目后能够直接开始新的 Creative Set |
| 研究和创意来源脱节 | 保存证据、推断和 concept 的关联 | 能回答这个创意为何提出、依据是什么 |
| 手工跨工具交接 | 将完整 brief、参考图和制作约束交给执行端 | 不必再次粘贴整段 ad/post set |
| 修改导致整套流程重来 | 识别影响范围，仅重跑需要变化的部分 | 换画风不重新研究，改 caption 不重新生图 |
| 风格和事实漂移 | 锁定 Brand Pack、Skill 及具体版本 | 一套内容中的产品、语气与风格约束可检查 |
| 输出难以复用 | 保存资产血缘、版本、选择理由和反馈范围 | 能继续修改旧作品，且不误写全局偏好 |
| 好点子暂时用不上 | 所有创意持久保存，收藏后可跨次继续发展 | 今天生成多个点子，只制作一两个，其余下次直接取用 |
| 每次研究都从头开始 | 研究与洞察独立沉淀，创作默认检索已有版本 | 不重新研究也能生成新创意；需要更新时由用户手动触发 |

## 产品原则

1. **保持质量后再减少操作。** 省时间不能以明显降低视觉质量为代价。
2. **知识属于项目。** 换 provider 或 agent，不丢品牌资料、创意记录和资产。
3. **订阅优先，费用透明。** BYOA 是首选路线，但每项能力都要验证；用户自己决定是否使用 API 计费。
4. **先选方向，再投入制作。** concept board 是重要决策界面，允许批量批准。
5. **事实和假设分开。** 保存过的模型输出不会自动成为品牌事实。
6. **工作流可解释、可恢复。** 用户知道运行到哪里、等待什么以及失败后怎么继续。
7. **形式为创意服务。** 整体生成和确定性合成都是合法制作方式。
8. **复杂度有进入条件。** 新角色、新 provider、新基础设施须解决已观察到的问题。
9. **项目长期积累，任务按需启动。** 一次 brainstorm 或 research 可以独立结束；保存与收藏不等于开始制作。
10. **积累靠相关性复用。** 只取当前任务需要的记忆；收藏是偏好线索，不是品牌事实或广告效果证据。

## V1 完整产品边界（原 v0.1 基线）

| 范围 | 本次决定 |
|---|---|
| 使用形态 | Windows 本机、浏览器界面、单个本地操作者、多项目 |
| 界面与内容语言 | 英文产品界面；每个 brief 独立选择生成内容语言，支持中文与英文 |
| 核心产物 | 静态单图、caption/广告文案、导出清单及内部创作记录 |
| 知识 | 手动导入文本/Markdown、品牌图像；确认、版本、引用、检索 |
| 研究与洞察 | 建项时可选初始化，之后手动触发；结果进入项目研究库与洞察库，日常创作默认复用 |
| 创意 | 可独立 brainstorm；创意版本持久保存、收藏、跨次复用；Paid / Organic set 引用选定创意，分批发展和制作 |
| 制作 | 一个主要原生 adapter；参考图、生成、文字指令编辑、资产回收 |
| 精确排版 | 一个可验证的基础合成模板；文字、logo 和视觉分层保存 |
| Skills | 导入、检查、项目启用、能力匹配和版本锁定；不做商城 |
| 治理 | 事实发布、制作方向、最终采用三个控制点，可按组确认 |
| 反馈 | 明确作用范围、作品选择记录、手动标记发布情况 |

完整自动生图能力能否进入 V1，取决于 M0 的可用性和质量证据；失败时按照路线图处理，不能把手动桥接包装成自动闭环完成。既有文字闭环不对生图、图片编辑或图片质量作通过声明。

## 暂不做

- 社交平台自动发布、排期日历、Meta 广告账户/投放预算管理。
- 团队协作、多租户 SaaS、云同步、远程控制和原生桌面壳。
- 通用 agent 聊天室、任意工作流画布、完整 Canva/Figma 编辑器。
- 视频、音频、复杂 carousel 成组排版和全渠道内容管理。
- 完整网站爬虫、付费数据采集、Reddit/G2 专用抓取系统。
- 自动证明广告效果、自动选择“最佳转化”方案、未经数据支持的营销学习。
- 定时自动研究、广告表现数据接入、自动 Taste Model、所有对象的通用收藏系统；这些是后续候选。
- 面向所有 provider 的自动模型 router、无限多 agent、自主改写品牌策略。

## 成功与取舍

北极星指标是 **每套被用户采用的图文内容所需的人工操作分钟数**，以质量不低于手工基线为前提。补充记录一次可用率、修改成功率、内容可追溯率、失败恢复和成本/用量可见性。

长期方向是减少重复交代背景，并利用积累的证据和选择记录改善创作。v0.1 验证前次知识或反馈能影响后续文字创作；完整跨次收藏续作与研究复用留在 V1。“越用越懂品牌”仍是待验证目标，不保证使用次数增加就自然提升质量、点击率或转化。

目标值与测量方法在[评测计划](evaluation.md)中；v0.1 已有受限文字记忆实测，V1 图文质量与操作时间尚无配对结果。个人每天有需求是已有证据，跨用户市场需求和收入模型尚未验证。

开放源码和可替换运行时是长期方向。v0.1 优先验证个人跨次创作的记忆闭环；只因参考项目拥有某项功能，不能据此将它加入范围。
